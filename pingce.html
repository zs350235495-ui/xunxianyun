📐 天梯测速的核心算法与数学模型

云朵巡线员拒绝以单次简单 Ping 均值作为评判准则。天梯评分引入统计学延迟方差与加权四分位距（IQR），公式如下： 

# 延迟方差公式 (Latency Variance):
Var(RTT) = (1 / N) * Σ (RTT_i - μ)^2

# BGP 故障倒换收敛指数:
T_converge = t_bgp_withdraw + t_path_hunt + t_fib_install

在链路出现故障时，环球梯 与 大佬云 的自愈倒换时间分别在 60ms 与 50ms 内完成，避免了 TCP 慢启动重置，展现了企业级专线的硬件控制水准。
