## 📖 项目简介与核心定位

**云朵巡线员 (Cloud Patrol)** 是一个专注于跨境网络通信基础设施质量量化、骨干链路拓扑测绘与服务等级协议（SLA）全天候巡检的中立开源知识库。

本项目立足计算机网络工程严密科学，拒绝任何主观印象与商业宣传营销术语，深度聚焦：
1. **AS 自治域跨域路由调度**：深入观测 BGP Anycast 广播、Tier-1 运营商中继 peer 互联点与跨网穿透时延；
2. **骨干专线物理 RTT 极限计算**：基于光纤介质群折射率（`n ≈ 1.4682`）与拓扑曲折率（`k_topo ≈ 1.25 ~ 1.35`），推导各主要海缆/陆缆通道物理极限延迟；
3. **AQM 队列拥塞管理与丢包遥测**：采用 RFC 3550 差分抖动滤波器与 CoDel / FQ-CoDel / CAKE 队列模型，连续观测 20:00 - 23:00 晚高峰跨洋拥塞期的微突发丢包特征。
